# 가운데에서 시작하는 분석 — 변경 설계

## 의도
엔진은 지금 노브가 어디 있는지 모른다. 그래서 다시 분석하면 FREQ를 옮길 때 이미 돌린 MID가 따라가는 문제, HIGH +6 / LOW +3 한도가 분석마다 쌓이는 문제, 끝까지 돌린 노브를 계속 더 돌리라는 문제가 생긴다(수학 검토 재검증). 분석할 때마다 EQ를 가운데에서 시작하게 하면 추천이 곧 "가운데에서의 위치"가 되어 이 문제들이 함께 사라진다. 앱은 가운데에서 한 번 맞춰 주고, 그다음 미세 조정은 사용자 귀에 맡긴다(사용자 결정). 다듬기를 포기하는 손해는 시뮬레이션에서 약 0.2 dB.

## 바꾸는 것
1. **분석 전 안내창**(`app.rs`): [분석]을 누르면(녹음 중의 [취소]는 그대로) 모달을 띄운다. 제목 `분석 전에 맞춰 주세요`, 줄은 고른 채널 그룹의 노브로 만든다:
   - `{EQ} 노브는 가운데(12시)로` — {EQ}는 그룹에 있는 것만 `HIGH·MID·LOW` 순서로(MID가 여러 개여도 한 번).
   - 저역컷이 있으면 `저역컷 끄기`, COMP가 있으면 `COMP는 왼쪽 끝(꺼짐)`(둘 다 있으면 한 줄: `저역컷 끄기, COMP는 왼쪽 끝(꺼짐)`).
   - `GAIN과 페이더는 그대로`
   - 흐린 글씨: `추천 각도는 가운데에서 돌릴 양입니다. 다시 분석할 때도 먼저 가운데로 돌려 주세요. 그다음 미세 조정은 귀로 하세요. 예배 중에는 소리가 바뀌니 사운드 체크 때 하세요.`
   - 버튼 `맞췄어요, 분석`(지금의 분석 시작과 똑같이 녹음 시작)과 `취소`(창만 닫음). Enter = 분석, Esc = 취소.
2. **엔진은 가운데·저역컷 꺼짐·COMP 꺼짐에서 잰다고 가정**(`advice.rs`):
   - 저역컷은 "켜세요"만 한다: 복구 모드의 "끄세요"(low < −3 dB) 분기를 없앤다.
   - COMP는 시계방향(+30°)만 한다: 크레스트가 낮을 때와 복구에서 DR이 저장보다 4 dB 넘게 작을 때의 −30°를 없앤다(과부하 안내 노트는 그대로).
   - 바뀐 동작에 맞게 기존 테스트(`restore_switch_both_ways`, `restore_from_saved_says_switch_off`, COMP −30° 테스트)를 고친다.
3. **노브 줄 안내**(`app.rs`): 노브 줄 가까이 흐린 글씨 한 줄 `각도는 가운데(12시)에서 돌릴 양`.
4. **저역컷 없는 채널에서 프리셋의 저역컷 빼기**(`target.rs` `preset_target`): 그룹에 저역컷이 없으면 `Move::Hpf`를 다른 "맡을 노브가 없는 move"처럼 빼서, 기존 노트 `이 채널에는 100Hz 부근을 바꿀 노브가 없어 그 부분은 빼고 맞춥니다.`가 나오게 한다(LOW가 저역컷 흉내로 6–15 dB 깎던 문제). 테스트: Soundcraft EPM(저역컷 없음)과 Signature 12 스테레오 그룹에서 저역컷 프리셋을 골랐을 때 목표에 HPF 모양이 없고 노트가 나옴.
5. **README**: 맨 위 사용법 문장, "분석" 항목(안내창), "노브 추천" 항목을 고친다. "돌린 뒤 다시 분석해서 확인하세요" → 각도는 가운데에서 돌릴 양, 다시 분석할 땐 먼저 가운데로, 미세 조정은 귀로. "✓"는 가운데(꺼짐) 그대로. "HIGH는 한 번에 최대 +6dB" → "HIGH는 최대 +6dB".

## 하지 않는 것
노브 위치 기억, 다듬기 반복, 한도 안에서 주파수 고르기, LOW 맞춤에 63·80 Hz 넣기, 하울링, 안내창 "다시 보지 않기".

`cargo test` 전체 통과 + 위 새/고친 테스트. 안내창은 가능하면 실제 앱 화면 캡처로 확인.
