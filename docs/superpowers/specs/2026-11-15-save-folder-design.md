# 저장 폴더 고르기와 읽기·쓰기 — 변경 설계

기존 설계: `2026-11-15-targets-and-restore-design.md`(저장과 복구). 이 문서에 없는 것은 기존 설계를 따른다.

## 의도
저장한 전문가 세팅 파일을 어느 로컬 폴더에 둘지 사용자가 고르고, 그 폴더의 파일을 직접 읽고 쓰고, 폴더를 바로 열어 볼 수 있게 한다. 사용자가 고른 용도: 로컬 파일 입출력(공유 폴더 아님).

## 하지 않는 것
여러 PC가 같은 폴더를 같이 쓰는 경우의 합치기·다시 읽고 쓰기(사용자가 뺌), 파일 하나를 골라 가져오기/내보내기, 폴더 안 여러 저장 파일.

## 접근 방식
- 폴더 선택 창: `rfd` 크레이트 `=0.17.2`(맥·윈도 기본 폴더 선택 창, 이번 변경의 유일한 새 의존성). osascript/PowerShell 호출은 느리고 깨지기 쉬워, 경로 직접 입력은 "브라우즈" 요청과 맞지 않아 제외.
- 폴더 열기: `open <폴더>`(맥), `explorer <폴더>`(윈도) — `std::process::Command`.
- 저장 파일은 목록 전체를 그대로 덮어쓴다(지금 방식). 합치기 없음.

## 화면 (왼쪽 패널 맨 아래 `저장 폴더` 묶음)
```
저장 폴더
/Users/…/MixerAnalyzer      ← 긴 경로는 줄임, 마우스를 올리면 전체
[찾아보기…] [폴더 열기]
[읽기] [쓰기]
```

## 동작
- 저장 파일은 `<폴더>/saved.tsv`(형식 그대로). 기본 폴더는 지금 위치(macOS `~/Library/Application Support/MixerAnalyzer`, Windows `%APPDATA%\MixerAnalyzer`).
- 고른 폴더는 기본 폴더의 `folder.txt`(한 줄, 경로)에 기억해 다시 켜도 유지. 없거나 비면 기본 폴더.
- 시작할 때 기억한 폴더가 없으면(지워졌거나 USB가 빠짐) 이번 실행은 기본 폴더를 쓰고 안내 `저장 폴더를 찾을 수 없어 기본 폴더를 씁니다: {경로}`. `folder.txt`는 그대로 둔다(다음에 폴더가 돌아오면 다시 씀).
- `찾아보기…`: 지금 폴더에서 시작하는 폴더 선택 창. 취소하면 아무것도 안 바뀜. 고르면 그 폴더가 저장 폴더가 되고 기억한다.
  - 그 폴더에 `saved.tsv`가 있으면 읽어 목록을 바꾼다(이전 폴더의 파일은 그대로 남음).
  - 없으면 지금 목록을 그 폴더에 쓴다(폴더 옮기기).
- `폴더 열기`: 저장 폴더를 Finder/탐색기로 연다. 아직 없으면 만들고 연다.
- `읽기`: `saved.tsv`를 읽어 목록을 바꾼다. 파일이 없으면 빈 목록.
- `쓰기`: 지금 목록으로 `saved.tsv`를 덮어쓴다.
- `이 소리 저장` / `삭제`: 지금처럼 목록 전체를 저장 폴더에 쓴다.
- 목록이 바뀌면(읽기, 폴더 바꾸기) 지금 고른 저장한 세팅은 이름으로 다시 찾고, 없으면 목표 `기본`.
- 오류(안내 줄에 빨간 글씨, 앱은 계속):
  - 읽기 실패(파일 없음은 오류 아님): `읽지 못했습니다: {오류}`. 목록은 그대로. 그 폴더에는 자동 쓰기(저장·삭제)를 하지 않는다 — 다시 읽기에 성공하거나, 다른 폴더를 고르거나, `쓰기`를 눌러 직접 덮어쓸 때까지(읽지 못한 파일을 몰래 덮어써 잃지 않게; 기존 규칙과 같은 뜻). 그동안 저장·삭제를 하면 목록에만 반영하고 안내 `저장하지 못했습니다: 읽지 못한 파일은 덮어쓰지 않습니다. [읽기]나 [쓰기]를 누르세요.`
  - 쓰기 실패: `저장하지 못했습니다: {오류}`.
  - 폴더 열기 실패: `폴더를 열지 못했습니다: {오류}`.
  - 기본 폴더를 정할 수 없음(HOME/APPDATA 없음): 지금처럼 `저장 폴더를 찾을 수 없습니다`, 찾아보기로 고르면 쓸 수 있다(기억은 못 함).
