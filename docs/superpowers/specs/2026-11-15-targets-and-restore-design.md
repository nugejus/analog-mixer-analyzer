# 그래프 정리, 추천 세팅, 세팅 복구 — 변경 설계

기존 설계: `2026-11-15-mixer-analyzer-design.md`, `2026-11-15-analyze-button-design.md`. 이 문서에 없는 것은 기존 설계를 따른다.

## 의도
- 그래프: 분석 결과를 더 촘촘하게, 덜 어지럽게, 필요한 정보만 골라 보고, 어느 구간이 어느 노브인지 보이게.
- 목표: 지금 목표(자연스러운 말소리, Byrne LTASS) 말고도 교회에서 알려진 보컬 EQ 세팅을 역할(찬양인도자·설교자·보조보컬)별로 골라 추천받게.
- 복구: 전문가가 귀로 맞춘 소리를 저장해 두고, 나중에 세팅이 틀어지면 지금처럼 "어느 노브를 어느 쪽으로 몇 도" 돌려 되돌리게.

## 하지 않는 것
실시간 평균선(사용자가 뺌), 밴드악기 목표(당분간 세팅하는 사람 감각에 맡김), 홀 모양(폭:길이) 보정(정확히 잴 수 없어 뺌), GAIN 복구(그날 말하는 크기에 따라 달라짐), 저장본 이름 바꾸기·내보내기, 말/노래·반주 유무 조건 표시와 사람별 노래−말 보정(조건은 이름에 적는다), 해상도·표시 선택 기억(앱을 다시 켜면 기본값).

## 접근 방식
- 추천 세팅: **목표 곡선**(선택) = 자연스러운 목소리 + 세팅의 EQ 변화. 실제 목소리·마이크를 반영해 이미 밝은 목소리면 HIGH를 더 올리라고 하지 않는다. 대안 "세팅표의 노브값을 그대로 보여주기"는 분석과 무관해서 제외.
- 복구: **소리 저장**(선택). 같은 사람 목소리끼리 비교하면 목소리는 상쇄되고 EQ 차이만 남으므로 지금 엔진으로 노브 변화량을 맞출 수 있다. 지금 노브 위치를 몰라도 된다. 대안 "노브 위치를 적어 두기"는 사진과 같고 계산이 없어 제외(README에 채널 스트립 사진도 찍어 두라고 적는다).
- 선 숨기기: egui_plot 범례 클릭도 되지만 찾기 어렵고 노브 구간은 범례 항목이 아니므로 체크박스를 둔다.

## 그래프
- `해상도` 콤보: `1/12옥타브` `1/24옥타브` `1/48옥타브`(기본) `1/96옥타브`. n = 옥타브당 점 수. 점 f_i = 20·2^(i/n), i = 0..=floor(n·log2(1000)) (120/240/479/957점). 각 점 = f·2^(±1/(2n)) 안의 빈 파워 합, 빈이 없으면 가장 가까운 빈(기존 규칙, 빈 범위는 산술로).
- 목표선 위치: `display_to_band_db(hz, sr, n)` = 10·log10(W3 / max(Wn, bw)), Wn = hz·(2^(1/(2n)) − 2^(−1/(2n))). 기존 식의 n=24 일반화.
- 분석 요약은 `display_db` 대신 활성 프레임의 **빈 파워 평균**(`bin_power`)을 저장하고, 표시 곡선은 현재 해상도로 그때그때 계산한다. 해상도를 바꿔도 재녹음이 필요 없다. (빈 합과 프레임 평균은 둘 다 선형이라 순서를 바꿔도 같다.)
- 해상도를 바꾸면 현재 소리(EMA)와 피크는 새 점 수로 다시 시작한다(피크 리셋과 같음).
- 피크 선: 색을 SURFACE2(어두운 회색)로, 다른 선보다 먼저(뒤에) 그린다. 범례 이름 `피크` 유지.
- `표시` 체크박스(그래프 제목 줄): `분석 결과` `현재 소리` `피크` `목표` `노브 구간`. 기본 모두 켬. 끈 항목은 그리지 않는다. 범례는 색 안내로 남긴다.
- `노브 구간`: 고른 믹서·채널그룹의 EQ 노브마다 그래프 위쪽(0 dB 부근)에 가로 막대와 이름. 이름은 아래 노브 줄 라벨과 같게(`저역컷 100Hz`, `LOW 80Hz`, `MID 2.5kHz`, `MID`/`MID 1`, `HIGH 12kHz`). 막대 범위:
  - 저역컷 hz, LOW 셸프 hz: 20 Hz–hz
  - HIGH 셸프 hz: hz–20 kHz
  - 고정 MID hz: hz·2^(±0.7) (Bell σ=0.6옥타브의 반값 폭)
  - 스윕 MID lo–hi: lo–hi (FREQ를 돌릴 수 있는 범위). 마지막 분석이 FREQ를 추천했으면(`SetFreq{hz}`) 그 hz에 세로 표시와 hz·2^(±0.7) 강조.
  - 막대끼리 겹치지 않게 줄을 나눈다.

## 목표 (추천 세팅)
- `목표` 콤보에 분류 제목을 두고 고른다: `기본`(자연스러운 목소리 = 지금 목표, 기본값) / `찬양인도자` / `설교자` / `보조보컬` / `저장한 세팅`. 닫힌 콤보 글자: `설교자 · 명료한 설교`. 고른 세팅의 한 줄 설명을 콤보 옆(또는 아래)에 SUBTEXT0으로.
- 남성/여성 버튼은 그대로, 기본·추천 세팅에 적용(바탕이 LTASS). 저장한 세팅을 고르면 비활성.
- 추천 세팅의 목표: target[b] = LTASS(voice)[b] + Σ move(BANDS_HZ[b]). move (f = 주파수):
  - hpf(fc): −10·log10(1 + (fc/f)^4) (2차, 12 dB/옥타브)
  - low_shelf(fc, g): g / (1 + (f/fc)²)
  - high_shelf(fc, g): g / (1 + (fc/f)²)
  - bell(fc, g, w): g·exp(−log2(f/fc)² / (2σ²)), σ = w / (2·√(2·ln2)); w = 0이면 σ = 0.6
- hpf move는 "로우컷 스위치 켜기"라는 뜻이다. 채널그룹에 `LowCut{hz}`가 있으면 표의 hz 대신 **그 스위치의 hz**로 목표를 만든다(75/80 Hz 스위치 믹서에서 켜도 안 맞는 목표가 되지 않게). 스위치가 없으면 표의 hz.
- 채널그룹에 해당 노브가 없는 move는 목표에서 뺀다(전체 레벨 c가 떠서 다른 노브가 엉뚱하게 크게 도는 것을 막음):
  - bell(hz): 스윕 MID lo ≤ hz ≤ hi, 또는 고정 MID f0에서 |log2(hz/f0)| ≤ 0.7일 때만 남김
  - high_shelf / low_shelf: 해당 셸프가 있을 때만
  - hpf: 항상 남김(스위치가 없으면 LOW가 맡는다)
  - 뺀 move가 있으면 안내: `이 채널에는 {fmt_hz(hz)} 부근을 바꿀 노브가 없어 그 부분은 빼고 맞춥니다.`
- 목표를 바꾸면 저장된 분석으로 다시 계산(재녹음 없음).
- 엔진(모든 목표 공통): 저역컷 `켜기 권장`(복구에서는 `끄기 권장`도)을 낼 때, 그 스위치 응답 hpf(스위치 hz)를 d에 반영한 뒤(켜기: d += hpf, 끄기: d −= hpf) EQ를 맞춘다. 스위치 판단 자체는 반영 전 d로 한다. 같은 저역 차이를 스위치와 LOW가 둘 다 쫓지 않게. (스위치 기울기는 12 dB/옥타브로 가정; 실제 믹서는 12–18 dB/옥타브.) 노래(인도자·보조보컬)도 바탕은 말소리 LTASS다(노래 장기 스펙트럼 표준표가 없어서; 세팅 곡선이 차이를 맡는다).
- 세팅 목록은 코드에 고정. 내용은 아래 "세팅 표".

## 세팅 표
출처 페이지를 실제로 열어 문구를 대조한 것만 넣었다(2026-11-15). 범위로 나온 값은 가운데. bell 폭은 출처에 없으면 0(σ=0.6). hpf 100 Hz는 믹서의 고정 로우컷 스위치에 맞춘 값(출처 범위 80–125 Hz 안).

| 분류 | 이름 | 설명(when) | move |
|---|---|---|---|
| 기본 | 자연스러운 목소리 | 목소리를 있는 그대로 자연스럽게 맞춥니다. | (없음) |
| 찬양인도자 | 또렷한 찬양 인도 | 밴드 소리에 인도자 목소리가 묻히고 가사가 잘 안 들릴 때 | hpf 100; bell 4000 +3; high_shelf 10000 +2.5 |
| 찬양인도자 | 가벼운 찬양 인도 | 밴드와 섞일 때 목소리가 두껍고 웅웅거릴 때(특히 남성 인도자) | hpf 100; bell 300 −4.5; high_shelf 10000 +2.5 |
| 설교자 | 명료한 설교 | 설교 말씀을 더 또렷하게 들리게 하고 싶을 때 | hpf 100; bell 3000 +4 |
| 보조보컬 | 리드 뒤로 | 보조보컬이 인도자와 겹쳐 같이 앞으로 튀어나올 때 | hpf 100; bell 3750 −3 |
| 보조보컬 | 남성 보조보컬 | 남성 보조보컬의 저음이 두꺼워 인도자나 악기를 덮을 때 | hpf 135; bell 300 −4.5 |

출처: Shure "Professional mixing tips for church sound"(Sokol: 4 kHz 약 +3 dB, 남성 로우컷 80 Hz), ProSoundWeb Huff "Seven keys to optimizing vocals in the worship mix"(HPF 80–120 Hz, 남성 250–350 Hz 3–6 dB 컷), ProSoundWeb Huff "Eight tips for improving clarity in speech"(HPF 80→125 Hz, 1–4 kHz 3–5 dB 부스트, 3 kHz에서 시작), Audient "How to EQ vocals"(프레즌스 2–4 dB, 10 kHz 위 2–3 dB), Sound On Sound "Vocal processing"(10 kHz 위 셸프 = air), Sweetwater 보컬 EQ 치트시트(BGV는 리드의 3.5–4.5 kHz를 2–4 dB 컷, 남성 HPF 120–150 Hz), ProSoundWeb Yakabuski "Making it sing"(HPF 100–200 Hz, 200–250 Hz 0.5–0.75옥타브 2–3 dB 컷), Carvin "Mixing lead and backing vocals live"(남성 BGV 저역 줄이기).

넣지 않은 것과 이유:
- 마이크 종류별 보정(가슴 핀마이크 730–800 Hz −3 dB, 헤드셋 300–400 Hz 컷): 마이크 자체의 색을 되돌리는 보정이라 자연스러운 목소리와 비교하는 지금 방식이 이미 그 컷을 추천한다. 목표에 더하면 두 번 깎으라고 한다.
- 부드러운 어쿠스틱(2.5–4 kHz 좁게 −6 dB): 좁은 컷은 장시간 평균 스펙트럼에서 넓은 MID 기준 약 1.5 dB로 퍼져 ✓ 범위 안이라 추천이 달라지지 않고, 거친 소리 보정은 기본 목표가 이미 잡는다.
- 구즈넥(Shure 연설 커브): 출처 페이지가 더 이상 열리지 않는다.
- 뭉침 정리(200–250 Hz 0.5–0.75옥타브 −2.5 dB, Yakabuski): 32개 믹서 44개 채널그룹 중 43개에서 추천이 hpf만 있을 때와 같다(✓ 범위 안). 부드러운 어쿠스틱과 같은 이유.
- 남성 보조보컬의 hpf 135(Sweetwater 120–150 Hz)는 스위치가 있는 채널에서는 스위치 hz가 된다(위 규칙).
- 출처끼리 다른 값: HPF 권장은 60–220 Hz로 넓다. 100 Hz는 가운데쯤이지 합의값이 아니다.

## 저장과 복구
- `이 소리 저장` 버튼: 마지막 분석에 요약이 있을 때만 켜짐. 누르면 이름 입력칸과 `저장`/`취소`. 이름(앞뒤 공백 제거)이 비면 `저장` 꺼짐. 예: `홍길동 목사님 설교 마이크`.
- 저장 내용: 이름, 믹서 이름(`{brand} {name}`), 채널그룹 라벨, 1/3옥타브 `bands_db` 25개, `dynamic_range_db`. 같은 이름이 있으면 덮어쓴다. 저장 직후 목표는 바꾸지 않는다.
- 파일: 데이터 폴더의 `MixerAnalyzer/saved.tsv` (macOS `~/Library/Application Support/MixerAnalyzer/`, Windows `%APPDATA%\MixerAnalyzer\`). 한 줄에 한 개, 탭 구분: 이름, 믹서, 채널그룹, dynamic_range_db, 밴드 25개. 이름·라벨의 탭·줄바꿈은 공백으로. 쓸 때는 임시 파일에 쓰고 rename(쓰다 꺼져도 기존 파일이 남게). 시작할 때 읽고, 읽을 수 없는 줄은 건너뛴다. 폴더가 없으면 만든다. 쓰기 실패는 안내 줄에 빨간 글씨 `저장하지 못했습니다: {오류}`로 보이고 앱은 계속(메모리에는 남김).
- `삭제`: 저장한 세팅이 목표로 골라져 있을 때만 보인다. 한 번 누르면 `정말 삭제`로 바뀌고, 그것을 누르면 지운다(파일에서도). 목표를 바꾸면 확인이 풀린다. 지운 뒤 목표는 `기본`.
- 복구 = 목표로 `저장한 세팅 · 이름`을 고르고 [분석]. 엔진에 target = 저장된 bands, `restore = true`:
  - EQ 맞춤은 지금과 같다. 단 LOW 부스트 상한 3 dB를 풀고 EQ_LIMIT_DB(15 dB)까지(전문가가 LOW를 올렸을 수 있음).
  - 저역컷: 양방향. 판단 값은 c0 대신 mean(d[63,80 Hz]) − mean(d[125,160 Hz])(LOW 셸프를 6 dB 넘게 돌린 것을 스위치로 잘못 읽지 않게). > 3 → `켜기 권장`, < −3 → `끄기 권장`(새 동작 `SwitchOff`, 스위치 그림은 꺼진 모양 + SAPPHIRE 글씨). 어느 쪽이든 위 "스위치 응답 반영" 뒤 EQ를 맞춘다.
  - COMP: 지금 dynamic_range − 저장 dynamic_range > 4 dB → 시계 30°, < −4 dB → 반시계 30°, 아니면 ✓. (기존 크레스트/다이내믹 규칙 대신.) 과부하 안내는 그대로.
  - GAIN: 기존 규칙(클리핑·너무 작음) 그대로.
  - 저장할 때와 믹서나 채널그룹이 다르면 안내: `저장할 때와 믹서/채널이 다릅니다(저장: {믹서} {채널}). 같은 채널에서 분석해야 맞습니다.`
  - 고른 세팅 설명 자리: `저장: {믹서} {채널} — 저장할 때와 같은 사람·같은 마이크로 분석하세요.`
  - 그래프 목표선 = 저장된 bands(지금처럼 level_offset과 해상도 보정을 더해서).
