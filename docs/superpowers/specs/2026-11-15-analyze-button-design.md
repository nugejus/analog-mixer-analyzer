# 분석 버튼과 유지되는 그래프 — 변경 설계

기존 설계: `2026-11-15-mixer-analyzer-design.md`. 이 문서에 없는 것은 기존 설계를 따른다.

## 의도
실시간 추천은 0.5초마다 최근 4초로 다시 계산되어, 말을 쉬면 "말씀을 계속해 주세요"로 바뀌고 각도가 계속 흔들린다. 봉사자가 읽고 돌릴 시간이 없다. 그래프도 0.3초 반응 선과 1.5초 뒤 떨어지는 피크라 모양을 보고 판단하기 어렵다.

## 목표
- **분석** 버튼: 정해진 시간(15–30초) 녹음 → 녹음 전체로 한 번 분석 → 추천을 다음 분석까지 그대로 둔다.
- 실시간 추천은 없앤다. 레벨 기록과 하울링 표시는 실시간 그대로(안전용).
- 주파수 그래프를 1/24옥타브(240점)로 촘촘하게.
- 분석 결과 곡선과 피크가 화면에 남는다.
- 실시간 선의 EMA 반응 속도를 고를 수 있다.

## 하지 않는 것
녹음 파일 저장, 자동 시작, 분석 시각 표시, 주파수 축 평활 옵션, 레벨 정규화 옵션(목표선이 이미 측정 레벨에 맞춰짐).

## 접근 방식
기존 egui 앱 안에서 바꾸는 것 하나뿐이다. "실시간 추천을 긴 창으로 유지" 안은 사용자가 실시간 추천을 빼라고 해서 제외. 추천 계산은 EMA가 아니라 녹음 구간의 단순 파워 평균을 쓴다(EMA는 최근 몇 초에 치우침).

## 녹음과 분석
- 상단: `녹음 [슬라이더 15–30, 정수, 기본 20] 초`, `분석` 버튼. 녹음 중엔 버튼이 `취소`.
- 녹음 길이는 오디오 프레임 수로 센다: 필요 프레임 = round(N초 / hop초), hop = 4096/샘플레이트.
- 시작 시 피크 곡선을 리셋한다.
- 녹음 중 하단: 진행 막대 `녹음 중 {경과:.0}/{N}초 — 계속 말씀하세요`. 입력이 끊기면(기존 `silent()`) 막대 아래 NO_INPUT 문구.
- 녹음 중 입력장치를 바꾸면 녹음 버림. 분석채널을 바꾸면 녹음 취소.
- 녹음이 끝나면 한 번 분석:
  - 활성 판정은 녹음 전체를 다 받은 뒤에 한다. 잡음 바닥 = 녹음 전체 프레임 RMS의 최솟값. 활성 = RMS > −60 dBFS 이고 > 바닥 + 12 dB.
  - 활성 말소리가 **5초** 미만이면 요약 없음.
  - 요약에 `display_db`(활성 프레임의 240점 표시 스펙트럼 파워 평균)를 더한다.
  - 클리핑 = 녹음 N초 안에 클리핑(`clipped_within(N)`). 하울링 = 녹음 중 마지막으로 감지된 주파수. 무음 = `silent_for(N)` 또는 스트림 정지.
  - 추천은 매번 새 `AdviceEngine`으로 계산(데드밴드 초기 상태 = ✓). 믹서·채널그룹·목표 음성을 바꾸면 저장된 분석으로 다시 계산(재녹음 없음).
- 요약 없음 문구(KEEP_TALKING): `말소리가 부족합니다. [분석]을 다시 누르고 녹음이 끝날 때까지 평소처럼 말씀해 주세요.`
- 첫 분석 전 하단: `[분석]을 누르고 {N}초 동안 평소처럼 말씀하세요.` (노브 없음)
- 분석 뒤 하단 제목: `노브 추천 — 말소리 {활성초:.1}초 분석`. 다음 분석 결과가 나올 때까지 유지(녹음 중에도 이전 결과를 보여 준다). 취소하면 이전 결과 유지.

## 그래프
- 표시 점: f_i = 20·2^(i/24) Hz, i = 0..=239 (240점, 20 Hz–19.9 kHz). 각 점 = f·2^(±1/48) 안의 빈 파워 합, 빈이 없으면 가장 가까운 빈. 빈 범위는 산술로 구한다(전체 스캔 금지).
- 1/24옥타브 점은 1/3옥타브 밴드보다 폭이 1/8이므로 목표선 위치 = LTASS + level_offset_db − 9.03 dB (10·log10(8)). 목표선은 분석 요약이 있을 때만.
- 선:
  - `분석 결과` GREEN, 굵기 2.5: 녹음 평균 `display_db`. 다음 분석까지 유지.
  - `현재 소리` BLUE: 실시간 EMA(파워 영역).
  - `피크` PEACH: 최대값 유지, 떨어지지 않음. `피크 리셋` 버튼과 분석 시작 때만 리셋.
  - `목표` SUBTEXT0 점선.
- `실시간 선` 콤보: `빠름 0.3초` / `보통 1초`(기본) / `느림 3초` = EMA τ.

## 없애는 것
0.5초 실시간 추천, 4초 창, `ADVICE_EVERY`, 호출 사이의 엔진 상태 유지, 피크 하강(1.5초 홀드, 12 dB/s).

## 배포
README의 화면 읽는 법 갱신. 맥(칩별 2개)·윈도 다시 빌드해서 드라이브에 올린다. 이전 파일 처리는 사용자에게 묻는다.
