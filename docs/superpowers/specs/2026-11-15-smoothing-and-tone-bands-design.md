# 주파수 평활, 대역 비교, 봉우리 표시 — 변경 설계

## 의도
그래프 선을 매끄럽게 해서 눈으로 모양을 읽기 쉽게 하고, "까랑한 비음"처럼 넓은 대역의 문제를 기준(목표나 저장한 전문가 소리)과 비교해 이름과 dB로 바로 보여 준다. 좁게 튀는 봉우리는 따로 표시할 수 있게 한다.

시험 그림(합성 한국어 음성에 1 kHz +7 dB, 3.2 kHz +8 dB를 넣음)에서 대역 비교는 비음 +6.9 dB·까랑함 +7.2 dB로 정확히 잡았고, 봉우리 찾기는 넓은 3.2 kHz 상승을 놓치고 정상 목소리의 포먼트(285 Hz)에도 표시가 붙었다 — 그래서 대역 비교가 주, 봉우리 표시는 보조(기본 꺼짐). 리서치(출처 확인 + 반박 검토 워크플로): 처음 안의 800–1500 / 2000–5000 Hz 사이 1.5–2 kHz 공백이 바로 "까랑한 비음의 하이 구간"이고, twang은 1–3 kHz 쪽이다.

## 하지 않는 것
노브 추천 계산 변경(추천은 지금처럼 25개 1/3옥타브 대역으로), 하울링 감지 변경, 실시간 선에 대한 대역 비교·봉우리 표시(분석 결과에만), 대역별 노브 안내 문구, 경계 dB 설정, 평활을 곡선 그리기 단계에서 하는 방식(실제로 없는 굴곡이 생김).

## 접근 방식
- 평활: 각 표시 점 f에서 ±1/(2N) 옥타브(반폭 hw = f·(2^(1/(2N)) − 1), 최소 FFT 한 칸) 안의 FFT 칸을 cos²(π/2 · (f_k − f)/hw) 가중치로 평균(파워 영역)하고, 그 점의 표시 대역에 들어가는 칸 수(f·(h − 1/h)/칸 폭, h = 2^(0.5/해상도), 최소 1)를 곱해 지금 표시와 같은 레벨 눈금을 유지한다. 그래서 `display_to_band_db`(목표선 위치 보정)는 그대로 맞다. 가중 창 반폭이 최소 한 칸이라 저음에서도 이웃 칸이 섞여 계단이 사라진다.
- 대역 비교: 분석 결과의 25개 1/3옥타브 대역 레벨(`Summary.bands_db`)과 그래프에 그리는 목표(`goal.db + level_offset_db`)를 구간마다 파워 합으로 비교한다 — 추천 엔진이 보는 것과 같은 차이.
- 봉우리: 분석 결과 bin 파워를 1/6옥타브로 평활한 곡선이 1옥타브 평활 곡선(주변 평균)보다 3 dB 이상 높고 ±1/6옥타브 안에서 가장 높은 점. 표시 평활과 상관없이 이 기준으로 찾는다.

## 화면
- 왼쪽 패널 `해상도` 아래 `주파수 평활` 콤보: `없음` / `1/24옥타브` / `1/12옥타브` / `1/6옥타브`(기본) / `1/3옥타브`. `없음`은 지금 방식 그대로.
- 평활을 바꾸면 피크 선을 지운다(새로 쌓음). 실시간 선·피크·분석 결과 모두 같은 평활.
- 그래프 `표시` 줄에 체크박스 두 개 추가(이름 색 = 그 표시의 색):
  - `대역 비교`(RED, 기본 켜짐): 분석 결과와 추천이 있을 때만. 각 구간을 그래프 세로 띠로, 기준보다 3 dB 이상 많으면 빨간 반투명, 3 dB 이상 적으면 파란 반투명(더 옅게), 그 사이는 칠하지 않음. 그래프 아래쪽 안에 구간 이름과 `+6.9 dB`(소수 한 자리, 부호 붙임); ±3 dB 이상은 그 색, 나머지는 흐린 글씨. 노브 구간 막대(위쪽)와 겹치지 않게 아래쪽.
  - `봉우리 표시`(PEACH, 기본 꺼짐; 기존 `피크`(피크 유지 선)와 헷갈리지 않게 이 이름): 분석 결과 곡선 위 ▼와 `892Hz +4dB`(1 kHz 이상은 `2.5kHz +4dB`), 100 Hz–10 kHz, 큰 순서로 최대 5개.

## 구간(이름, 범위)
서로 겹치지 않게 1/3옥타브 대역 중심 기준으로 나눈다(범위 [lo, hi)에 중심이 드는 대역을 합산; 띠는 lo–hi에 그림).

| 이름 | 범위 | 1/3옥타브 대역 | 근거(요약) |
|---|---|---|---|
| 웅웅거림 | 80–250 Hz | 80–200 | iZotope 100–400, Neumann 근접효과 200 Hz 아래, Audient HPF 80 |
| 먹먹함 | 250–500 Hz | 250–400 | iZotope·Audient·QSC 200–500 |
| 통 울림 | 500–800 Hz | 500–630 | iZotope 400–800, eMastered 500–800 |
| 비음 | 800–1500 Hz | 800–1250 | SOS(White)·iZotope 800–1.5k |
| 까랑함 | 1.5–3 kHz | 1600–2500 | iZotope harsh 1.5–5k, eMastered 비음 1.5–2k, Saldías 2024 twang↔1–2k(r=.51)·2–3k(r=.42) |
| 쏘는 소리 | 3–5 kHz | 3150–4000 | ProSoundWeb(교회 음향) 2.5–4k, eMastered 2–5k |
| 치찰음 | 5–10 kHz | 5000–8000 | iZotope·QSC 5–8k, Audient 5–10k |
| 공기감 | 10–20 kHz | 10000–16000 | Audient·eMastered 10k+, SOS 10–15k+ |

- 비교값 = 10·log10(Σ 측정 대역 파워 / Σ 기준 대역 파워), 기준 = `goal.db + level_offset_db`. 경계 ±3 dB(휴리스틱, 고정).
- 2.4–3.6 kHz는 좋은 울림(가수 포먼트)과, 200–500 Hz는 따뜻함과 겹친다 → 절대값이 아니라 기준 대비라 괜찮다.
- 장기 평균이라 치찰음처럼 순간적인 것은 덜 보인다. 1/6옥타브 평활은 Q 약 8.6보다 좁은 울림을 보여 주지 못한다 → 하울링은 기존 하울링 표시로(README에 한 줄씩).
