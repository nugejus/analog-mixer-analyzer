# 그대로 분석에서 노브 위치 입력 — 변경 설계

## 의도
0.4.0의 노브 위치 추정(가운데 소리와 완성 소리로 거꾸로 계산)은 이 쓰임에서 필요 없고 미덥지 않다(사용자 결정). 대신 **지금 세팅 그대로 분석**에서 녹음이 끝나면 사용자가 노브 위치를 믹서 눈금대로 입력한다. 그러면:
- 저장 세팅이 소리와 함께 **정답 노브 위치(라벨)**를 갖는다. 추정 오차가 없다.
- 불러온 세팅의 라벨대로 맞추고 그대로 분석하면, 오늘 소리와 저장한 소리의 차이로 **라벨에서 얼마나 더 돌릴지(상대 조정)**를 알려 준다.
- 프리셋 목표도 같다. 노브 눈금을 읽어 입력하면 가운데로 되돌리지 않고 지금 위치에서 추천을 받는다.

`2026-11-16-knob-settings-design.md`의 추정 부분(가운데 소리 저장, `last_flat`, 지금 노브 추정, 차이 노트)을 이것으로 바꾼다. flat-start의 가운데 분석은 그대로 둔다(노브 위치 = 모두 가운데로 입력한 것과 같음).

## 노브 위치(`Positions`)
그룹의 노브 라벨(`advice::labels`, GAIN 제외)마다 값 하나. 순서와 이름은 `labels`와 같다.
- HIGH·MID·LOW(EQ): 가운데에서 dB, −15…+15 정수.
- FREQ: Hz, 그 노브의 후보(엔진과 같은 1/3옥타브 공칭값 중 범위 안). 0은 "모름"(가운데 분석).
- 저역컷: 1 켬, 0 끔.
- COMP: 왼쪽 끝에서 각도, 0…300, 5° 단위. 0은 꺼짐.
가운데 = EQ 0, FREQ 0, 저역컷 0, COMP 0.

## 엔진(`advice.rs`)
`Inputs`에 지금 노브 위치 K를 더한다(없으면 가운데). K가 있으면:
- **가운데 소리로 바꿔 계산**: 측정 대역에서 K의 EQ 모양(엔진의 Shape 함수, 저역컷 켬이면 `hpf_db`)을 빼서 가운데에서 잰 소리로 보고, 지금과 같은 계산으로 목표 위치(절대값)를 구한다. 한도(±15, 보통 모드 HIGH +6·LOW +3, 대역 가드)는 목표 위치에 건다.
- **✓는 지금 위치 기준**: |목표 − K| ≤ 2.5 dB면 ✓(그대로 둠). 아니면 `Rotate { degrees: 지금에서 돌릴 각도, db: 목표 위치 dB }`.
- **FREQ**: K의 FREQ를 지난 추천 주파수로 넣어(기존 20% 히스테리시스) 소리가 같으면 그대로 둔다. 고른 주파수가 K와 다르고 그 MID 목표가 ✓ 범위(|목표| ≤ 2.5) 밖이면 `SetFreq`, 아니면 ✓. MID의 ✓ 판단은 위와 같이 목표 − K.
- **저역컷**: K가 켬이면 늘 ✓(끄라고 하지 않음)이고, 맞춤은 켜진 것으로 계산한다. K가 끔이면 지금처럼 켜기만 판단한다.
- **COMP**: K ≥ 30°면 ✓. 아니면 지금 규칙(보통: 크레스트·DR, 복구: DR − 저장 DR > 4)이 참일 때 왼쪽 끝에서 30°까지 돌리게 한다(`degrees` = 30 − K).
- **GAIN**: 지금과 같다(지금 위치에서).
- K가 가운데면 결과가 지금 엔진과 같다.

꼭 지켜야 하는 성질:
- **같은 소리면 모두 ✓**: 저장한 소리를 만든 노브 위치를 K로 넣고 같은 소리를 분석하면(복구 모드) 모든 노브가 ✓다. 모든 믹서·그룹에서.
- 고정 MID 그룹에서 K로 분석한 목표 위치는 같은 가운데 소리를 가운데 분석한 추천과 0.5 dB 안에서 같다.

## 분석과 입력(`app.rs`)
- 안내창 버튼은 그대로(`가운데로 맞췄어요, 분석` / `지금 세팅 그대로 분석` / `취소`). 흐린 글씨를 고친다.
  - `가운데 분석의 추천 각도는 가운데에서 돌릴 양입니다. 그다음 미세 조정은 귀로 하세요. 예배 중에는 소리가 바뀌니 사운드 체크 때 하세요.`
  - `노브를 돌려 둔 채로 분석하거나 세팅을 저장할 때는 '지금 세팅 그대로 분석'을 누르고, 녹음이 끝나면 노브 위치를 입력하세요.`
- **그대로 분석이 끝나면**(말소리 충분, 샘플레이트 40 kHz 이상) 노브 줄이 입력 칸으로 바뀐다.
  - 머리글 `지금 노브 위치를 믹서 눈금대로 입력하고 [확인]을 누르세요.`
  - EQ: dB 숫자 칸(−15…15, 정수, `dB`). FREQ: 후보 목록. 저역컷: `켬` 체크. COMP: 각도 칸(0…300, 5°, `°`)과 아래 흐린 글씨 `왼쪽 끝에서`. GAIN: 흐린 글씨 `입력 안 함`.
  - 버튼 `확인`.
  - **미리 채움**: 분석 직전 노브 줄이 보여 주던 목표 위치. 저장된 세팅이면 그 위치, 추천이면 추천대로 돌린 위치(✓는 그때의 K), 그 밖에는 가운데.
- 쓸 수 없는 그대로 분석(말소리 부족, 낮은 샘플레이트, 입력 없음)은 지금처럼 노브 이름과 엔진의 그 이유 노트만.
- `확인`을 누르면 입력한 위치가 그 분석의 K가 되고 추천이 나온다. 머리글 `추천: 입력한 위치에서 돌릴 양` 옆에 버튼 `입력 고치기`(입력 칸을 그 값으로 다시 연다).
- 입력한 위치는 입력한 그룹에서만 쓴다. 믹서·그룹을 바꾸면 그 그룹의 미리 채움으로 입력 칸을 다시 연다.

## 노브 줄(우선순위대로)
1. 입력 칸이 열려 있음 → 입력 칸.
2. 가운데 분석 → 가운데에서의 추천. 머리글 `추천: 가운데(12시)에서 돌릴 양`.
3. 확인한 그대로 분석 → 입력한 위치에서의 추천. 머리글 `추천: 입력한 위치에서 돌릴 양` + `입력 고치기`.
4. 쓸 수 없는 그대로 분석 → 노브 이름 + 이유 노트.
5. 분석 없음, 고른 저장 세팅에 노브 위치가 있고 믹서·그룹이 같음 → 저장된 위치. 머리글 `저장된 세팅: 가운데(12시)에서 돌릴 양`.
6. 그 밖 → 지금과 같음.

**저장된 노브 줄**: 고른 저장 세팅에 노브 위치가 있고 믹서·그룹이 같으면, 분석이 있든 없든 노브 줄 머리글 아래에 한 줄 `저장된 노브: …`를 둔다. 가운데가 아닌 노브만 그룹 순서대로 `저장된 노브: 저역컷 켬 · HIGH 12kHz +6dB · FREQ 800Hz · MID -6dB · LOW 80Hz -3dB · COMP 30°`처럼 쓴다(FREQ는 그 MID가 0이 아닐 때만, 부호는 ASCII). 모두 가운데면 `저장된 노브: 모두 가운데(저역컷·COMP 꺼짐)`.

**다이얼과 설명**(K가 있으면 K에서, 가운데 분석과 저장된 위치는 가운데에서):
- EQ: 바늘은 지금 위치, 호는 지금 위치에서 목표까지. 설명 `{시계방향|반시계} {각도}°`와 `({목표:+}dB 눈금으로)`. ✓는 바늘만 지금 위치에.
- FREQ: `SetFreq`는 지금처럼 목표 눈금에 바늘. ✓이고 K의 FREQ가 있으면 그 눈금에 흐린 바늘.
- 저역컷: K가 켬이거나 `켜기`면 켜진 그림.
- COMP: 바늘은 −150° + K, 호는 30°까지. 설명 `왼쪽 끝에서 {목표}°로`.
- GAIN: 지금과 같음(`(지금 위치에서)`).

## 저장
- 가운데 분석 뒤: 소리 + 노브 위치 가운데.
- 확인한 그대로 분석 뒤: 소리 + 입력한 위치.
- 확인 전 그대로 분석: `이 소리 저장`을 막고 마우스를 올리면 `노브 위치를 입력하고 [확인]을 누르면 저장할 수 있습니다.`

## 파일 형식(`saved.tsv`)
- 30필드 뒤에 노브 위치 한 필드: `라벨=값`을 `;`로 이어 쓴다(예: `저역컷 100Hz=1;HIGH 12kHz=6;FREQ=800;MID=-6;LOW 80Hz=-3;COMP=30`). 샘플레이트와 노브 위치가 둘 다 있을 때만 31필드, 아니면 지금처럼 30·29필드.
- 29·30·31·56필드를 읽는다. 56필드(0.4.0의 가운데 소리)는 소리만 읽고 노브 위치는 없음. 31필드의 노브 필드가 `라벨=숫자` 꼴이 아니면 읽지 못한 줄(쓰기 막음). 다른 개수도 읽지 못한 줄.
- 라벨이 그룹의 라벨과 정확히 맞지 않는 노브 위치는 쓰지 않는다(소리만).
- 0.4.0은 31필드 줄을 읽지 못하고 쓰기를 막는다(지워지지는 않음). README의 "0.4.0 이상"은 "0.5.0 이상".

## README
- 분석 항목: 두 분석과 입력 칸, `입력 고치기`.
- `세팅 저장과 복구`:
  - 전문가: ① 가운데로 맞추고 분석(또는 노브를 읽을 수 있으면 그대로 분석 + 입력) ② 추천대로 돌리고 귀로 다듬기 ③ 지금 세팅 그대로 분석 → 노브 위치 입력(추천대로 채워져 있으니 바꾼 것만 고침) → 확인 ④ 이 소리 저장.
  - 봉사자: 저장 세팅을 고르면 `저장된 노브`와 노브 줄에 위치가 나온다. 그대로 맞추고 지금 세팅 그대로 분석 → 확인(저장된 위치가 채워져 있음) → 남은 조정만 돌린다.
- 0.4.0의 추정 문장(LOW 오차, 같은 사람·마이크로 두 분석 등) 지우기. 공유 폴더 "0.5.0 이상".

## 하지 않는 것
GAIN·페이더 위치 입력과 저장, 노브 위치 기억(앱을 다시 켜면 입력 칸은 미리 채움부터), 저역컷·COMP 끄라는 추천, 저장 세팅 여러 개 비교.

## 확인
- 같은 소리면 모두 ✓(모든 믹서·그룹, 여러 K).
- 고정 MID 그룹에서 K 입력 결과 = 가운데 분석 결과(0.5 dB).
- 작은 변화: 오늘 소리가 저장보다 HIGH 쪽 3 dB 어두우면 HIGH만 +3 근처, 나머지 ✓.
- FREQ만 옮기면 되는 경우: FREQ `SetFreq`, MID ✓.
- 저역컷 켬 K는 끄라는 말 없음. COMP K ≥ 30은 ✓.
- 31/56/30/29필드 읽기와 31필드 왕복, 잘못된 노브 필드는 읽지 못한 줄.
- 노브 줄 규칙 1–6, 미리 채움, 저장 막기, `저장된 노브` 줄 문구를 순수 함수로 테스트.
- `cargo test`·clippy 깨끗. 입력 칸은 실제 앱 화면 캡처로 확인.
